# BTW-Bedrock Edition Prototype

This repository contains an improved prototype of the BTW-Bedrock Edition add-on for Minecraft Bedrock.

Contents:
- behavior_pack: block/item definitions, scripts, and recipes
- resource_pack: placeholder textures and texture atlas definitions

Notes:
- The PNG files in the resource pack are placeholders (1x1 transparent) — you should replace them with proper 16x16 textures.
- Import both .mcpack files into Minecraft and enable Experimental Gameplay to run scripts.
